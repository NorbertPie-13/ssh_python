# SSH In Python with Paramiko

## Dependencies
- python3.12
- paramiko>=4.0.0
- Dropbear v2022.83

**NOTE: These configurations were tested against a Dropbear v2022.83**

***WARNING: These practices are not for production use***

## Dropbear
### Installing Dropbear
Dropbear is a lite-weight SSH program that can run minimally on several different platforms. It sometimes is used as an alternate for Openssh due to its minimal package size.

Dropbear can be install with the following:

```sudo apt-get install dropbear -y```

### Creating Keys for Dropbear
Dropbear uses a unique format for its keys. A key can be generated by use of the ```dropbearkey``` tool, or a key can be converted with use of ```dropbearconvert```.

***WARNING: dropbearconvert is not a tool for production. Please read its help with "-h"***

```dropbearkey -t rsa -f dropbear.db```

### Running Dropbear

Dropbear will run as a **background process** unless specifically told otherwise. It also logs to syslog unless passing ```-E```.

```sh
Usage: dropbear [options]
-b bannerfile   Display the contents of bannerfile before user login
                (default: none)
-r keyfile      Specify hostkeys (repeatable)
                defaults:
                - dss /etc/dropbear/dropbear_dss_host_key
                - rsa /etc/dropbear/dropbear_rsa_host_key
                - ecdsa /etc/dropbear/dropbear_ecdsa_host_key
                - ed25519 /etc/dropbear/dropbear_ed25519_host_key
-R              Create hostkeys as required
-F              Don't fork into background
-e              Pass on server process environment to child process
-E              Log to stderr rather than syslog
-m              Don't display the motd on login
-w              Disallow root logins
-G              Restrict logins to members of specified group
-s              Disable password logins
-g              Disable password logins for root
-B              Allow blank password logins
-t              Enable two-factor authentication (both password and public key required)
-T              Maximum authentication tries (default 10)
-j              Disable local port forwarding
-k              Disable remote port forwarding
-a              Allow connections to forwarded ports from any host
-c command      Force executed command
-p [address:]port
                Listen on specified tcp port (and optionally address),
                up to 10 can be specified
                (default port is 22 if none specified)
-P PidFile      Create pid file PidFile
                (default /var/run/dropbear.pid)
-i              Start for inetd
-W <receive_window_buffer> (default 24576, larger may be faster, max 10MB)
-K <keepalive>  (0 is never, default 0, in seconds)
-I <idle_timeout>  (0 is never, default 0, in seconds)
-z    disable QoS
-V    Version
```

For this example we will be running Dropbear in the foreground.

```sh
dropbear -F -E -p 2222 -r dropbear.db
```

Your dropbear server should now be running and be binded to port 2222.


## Paramiko Client
Paramiko is a python package that is specifically designed to communicate via SSH in python. 

### Paramiko Key Generation

Generate a new SSH authenication key for use with the dropbear server. Paramiko will be using this key later to authenticate the client.

```sh
ssh-keygen -t rsa -f client_key 
```

After generating the key, the public key needs to be added to the authorized hosts on the dropbear server. In production this can be done via ```scp``` or another File Transfer Protocol.

***WARNING: Be aware of adding authorized keys, as this allows for passwordless connection***

```sh
cat client_key.pub >> ~/.ssh/authorized_keys
```

After the public key has been added to the authorized keys, Paramiko can now do passwordless connection.

### Paramiko Client tool

The paramiko client tool converts an RSA key by use of paramiko.RSAKey. paramiko_client.py then uses paramiko.SSHClient() to establish an ssh connection. Below is an example using tool.

**```key```**: Specify the key to be used for authenticating the SSH Client.

```sh
./paramiko_client.py key client_key
```

If everything works correction, the python program should make an SSH connection and then echo ```Hello World``` on the Dropbear SSH server.
